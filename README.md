# これ食べていい？LINE相談 — 初回モニター募集LP

`index.html` 1ファイル（HTML＋CSS）のスマホ向けランディングページです。
画像は `images/` フォルダにあります。

## 公開前に差し替える箇所（【 】の部分）

| 箇所 | 場所 |
| --- | --- |
| 【決済ページのURL】 | 申し込みボタン4か所（ファーストビュー／料金の下／最後／画面下の固定ボタン） |
| 【◯月◯日 23:59】 | ファーストビュー／料金表／最後のブロック |
| 【例：72時間以内に返信がなかった場合は全額返金】 | 料金表の「返金」 |
| 【特定商取引法に基づく表記のURL】 | フッター |
| 【とも子さんの写真のURL】 | 「とも子について」の写真（今はイラスト） |
| 【OGP画像のURL】 | `<head>` 内。LINEでシェアされたときの画像 |

エディタで `【` を検索すると、すべて見つかります。

## 画像

キャラクターのイラストは、キャラクターシート（1024×1024）から切り出し、AIで4倍に拡大して高画質にしたものです。
差し替えるときは同じファイル名で上書きするか、
`index.html` の `<!-- 画像差し替え：… -->` コメントの下にある `src` を変更してください。

- `header.webp` … ファーストビューのヘッダー画像（1672×941）。
  元画像の「2,980円の打ち消し線」「約67%OFF」は定価との比較表示になるため、
  「初回モニター価格」「先着10名」に描きかえています
- `tomoko-pose-think.webp` … お悩み
- `tomoko-pose-pray.webp` … モニター募集について
- `tomoko-pose-open.webp` … ご利用の流れ
- `tomoko-face-smile.webp` … 相談の例のアイコン／とも子について
- `tomoko-pose-guts.webp` … 最後の申し込み
- そのほか（OKサイン・指差し・お椀・正面全身など）は予備です

「相談の例」の写真部分は、点線の仮の枠（`.photo-slot`）になっています。
