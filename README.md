| 箇所 | 場所 |
| --- | --- |
| 【例：72時間以内に返信がなかった場合は全額返金】 | 料金表の「返金」 |

差し替えるときは同じファイル名で上書きするか、
`index.html` の `<!-- 画像差し替え：… -->` コメントの下にある `src` を変更してください。
